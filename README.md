# LangChain — Chains

My digital notes and practical experiments while learning **Chains in LangChain**.

This repository focuses on understanding how LangChain components can be connected
together to create composable, reusable, and flexible LLM workflows.

## 📚 Notebooks

| # | Notebook | Description |
|---|---|---|
| 1 | `chains_overview.ipynb` | An introduction to LangChain Chains and how components can be connected to build structured LLM workflows. |
| 2 | `simple chain.ipynb` | Demonstrates a basic chain by connecting prompts, language models, and output parsers into a simple workflow. |
| 3 | `sequential_chain.ipynb` | Explores sequential workflows where the output of one step becomes the input to the next step. |
| 4 | `parallel_chain.ipynb` | Demonstrates parallel execution of multiple Runnable components within a LangChain workflow. |
| 5 | `conditional_chain.ipynb` | Explores conditional branching and dynamically routing inputs through different processing paths. |
| 6 | `Runnable_lambda.ipynb` | Demonstrates `RunnableLambda` for converting custom Python functions into composable Runnable components. |
| 7 | `Runnable_passthrough.ipynb` | Explores `RunnablePassthrough` for forwarding input data unchanged while composing it with other Runnables. |
